# ¿Sabías que ahora puedes modificar el orden de las líneas de oferta?

En las últimas versiones de la aplicación CRM by FLEXYGO, se ha añadido la opción de modificar o cambiar el orden de las líneas de oferta, para que se puedan ver en el orden requerido, tanto a la hora de visualizar como a la hora de imprimir los informes.

Para acceder a esta nueva funcionalidad, si editamos la oferta, dispondremos de sendas flechas arriba/abajo para alterar el orden de la línea cambiando su posición con la línea anterior/posterior.
