# Ejemplo proceso Crm by Flexygo Envio Pdf por mail.

Se trata de un proceso integrado dentro del producto Crm by Flexygo.

Consiste básicamente en enviar un mail con un fichero pdf de la oferta, basado en el report asociado al objeto de Oferta.

Nombre del proceso: crm_Oferta_EnviarPDFPorMail

Ruta: ~/bin/FlexygoCRM_Processes

Espacio de nombres (Class): FlexygoCRM.Mail

Método: SendPDFReportByEmail

  

Adjuntamos código fuente del mismo, con el objetivo de servir como ejemplo para implementar procesos similares o estudiar el acceso desde el entorno de desarrollo Flexygo a objetos y reports.
